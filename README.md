## O produto inusitado

A Coward funciona apartir da seguinte necessidade humana, você já deixou de fazer algo que gostaria apenas por falta de coragem? Se sim, seus problemas acabaram. A Coward vende kits digitais com roteiros, frases e estratégias para quem trava na hora de agir. Cada pacote cobre um medo do dia a dia, como mandar aquela mensagem, cobrar um PIX, sobreviver ao almoço de família, fazer uma apresentação, pedir um aumento ou apertar enviar no áudio. O produto é absurdo porque coragem não se compra, mas a página tenta convencer o visitante de que ele precisa de uma.

## Tecnologias utilizadas

- HTML5 (tags semânticas)
- CSS3 (variáveis, Flexbox, Grid, media queries, animações)
- JavaScript puro (sem frameworks)
- Google Fonts (Inter e Archivo Black)

## Funcionalidades interativas

- Menu responsivo que abre e fecha no mobile
- Menu fixo ao rolar a página
- Scroll suave entre as seções
- Alternância de tema claro/escuro (preferência salva no `localStorage`)
- Modal de carrinho funcional, com contador e total (carrinho salvo no `localStorage`)
- Efeitos de hover, tooltips e animação ao carregar a página
- Sistema de avaliações: formulário com validação em JavaScript, nota em estrelas, média geral, média por pacote e exclusão de avaliações (salvo no `localStorage`)
- Perguntas frequentes em acordeão
- Botões de Call To Action

## Como rodar localmente

1. Clone o repositório:
   ```bash
   git clone [https://github.com/JVMotasales/Coward---Seja-mais-forte-que-o-medo.]
   ```
2. Entre na pasta do projeto:
   ```bash
   cd [Coward V1.6]
   ```
3. Abra o `index.html` no navegador (ou use a extensão **Live Server** do VS Code, clicando em Go Live).

Não há dependências para instalar.
